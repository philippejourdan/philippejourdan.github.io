Smart Contract — ERC-20

AlyraToken.sol — Solidity ^0.8.20 ERC-20 
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract AlyraToken is ERC20 {
  constructor(uint256 initialSupply)
    ERC20("AlyraToken", "ALY")
  {
    _mint(msg.sender, initialSupply * 10 ** decimals());
  }
}

// Concept · DID · DAO · Recrutement

Web3 Talent Protocol

Concept · Idéation DID · DAO · Smart CV Idéation

Le problème

Le CV traditionnel est un document centralisé, falsifiable et statique. Dans un écosystème Web3 où les contributions sont publiques, vérifiables et immuables on-chain, il existe une opportunité radicale : remplacer le CV par des credentials décentralisés.

🖼
Schéma du protocole — à ajouter

Les 3 couches du protocole

  • Identité — Decentralized Identifiers (DID) : identité professionnelle auto-souveraine, non liée à une plateforme
  • Vérification — Smart contracts signés par l'employeur on-chain : expériences et compétences vérifiables sans intermédiaire
  • Réputation — Système de score DAO basé sur les contributions open-source, audits et participations à des protocoles

Cas d'usage concret

Une DAO qui recrute un Solidity Developer pourrait vérifier en quelques secondes ses contributions GitHub, ses déploiements on-chain et sa réputation dans d'autres DAOs — sans intermédiaire RH, sans CV falsifiable, sans processus opaque.

Pourquoi c'est pertinent maintenant

  • L'écosystème Web3 recrute nativement sur Discord, GitHub et Snapshot — pas sur LinkedIn
  • Les profils Web3 ont déjà une empreinte on-chain publique et vérifiable
  • Les DAOs ont besoin de systèmes de recrutement compatibles avec leur gouvernance décentralisée
  • L'identité décentralisée (DID / ERC-725) est en voie de standardisation

Ecosystem Mapping Web3

Veille active Research · Mapping Actif

Objectif

Cartographier les acteurs Web3 sous l'angle recrutement : pour chaque segment (DeFi, NFT, L2s, DAOs, GameFi), identifier les profils les plus recherchés, les niveaux de rémunération, et les canaux de sourcing spécifiques à l'écosystème décentralisé.

Segments analysés

  • DeFi — Uniswap, Aave, Curve, Lido : Solidity Devs, Protocol Engineers, Security Auditors
  • L2 & Infrastructure — Arbitrum, Optimism, zkSync : ZK Engineers, Core Devs, DevRel
  • NFT & GameFi — Studios NFT, Axie, Immutable : Full Stack Web3, Smart Contract Devs
  • DAOs — MakerDAO, Compound, ENS : Contributors polyvalents, Governance Analysts
  • Infrastructure — Alchemy, Infura, The Graph : API Engineers, Indexers

Canaux de sourcing Web3

  • Discord — serveurs de protocoles et communautés de développeurs
  • GitHub — contributions open-source, profils actifs sur projets EVM
  • Twitter/X — threads techniques, participation aux débats de gouvernance
  • Snapshot — votes de gouvernance DAO, identification des contributors actifs
  • Etherscan / Dune Analytics — activité on-chain comme signal de compétence

Insight clé

Les meilleurs profils Web3 ne sont jamais en recherche active. Ils contribuent à des protocoles, participent à des hackathons et vivent dans des communautés Discord. La valeur ajoutée d'un recruteur Web3 est précisément d'aller les chercher là où ils sont — pas sur LinkedIn.
